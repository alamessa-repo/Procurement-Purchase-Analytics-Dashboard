## 🚀 Project Overview

This project demonstrates an end-to-end Procurement Analytics solution built in **Microsoft Power BI**.

The dashboard enables procurement teams, finance departments, and business leaders to monitor purchasing trends, supplier performance, purchase order volumes, and product/category spending across multiple financial years.

The objective is to transform raw procurement data into actionable insights that support:

- Cost optimization
- Supplier performance analysis
- Purchasing trend monitoring
- Budget planning
- Procurement decision-making

---

# 📌 Business Problem

Organizations often struggle to answer critical procurement questions:

- How is purchasing spend changing over time?
- Which suppliers account for the largest spend?
- Which product categories drive procurement costs?
- How many purchase orders are generated monthly and yearly?
- Are there seasonal purchasing patterns?
- Which products contribute most to purchasing expenditure?

This dashboard addresses these challenges through interactive analytics and drill-down capabilities.
